# Sql-Task6
This project focuses on analyzing monthly sales performance using SQL queries on an online retail dataset.
It includes a ready-to-run MySQL script with database setup, sample data, and trend analysis queries using YEAR(), MONTH(), SUM(), and COUNT().
The goal is to understand revenue fluctuations and order volume patterns across months.
This repository is ideal for beginners learning SQL aggregation and time-series analysis.
You can execute the script in MySQL Workbench and extend it for deeper insights.
